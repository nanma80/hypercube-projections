# 8D → 4D Maximum Shadow Projection: Analysis Results

## Problem Statement

Find the 4D subspace W ⊂ ℝ⁸ that maximizes Vol₄(proj_W([0,1]⁸)).

Equivalently: maximize the volume of the zonotope generated by projecting
the 8 standard basis vectors of ℝ⁸ onto a 4D subspace.

This continues the pattern: 4→2 gives a regular octagon, 6→3 gives the
rhombic triacontahedron. What does 8→4 give?

## Background: The Sin/Cos Parameterization

Starting from unconstrained optimization over all 4×8 projection matrices
(max_shadow.py, max_shadow_8_4.py), the optimal projection matrix was found
numerically (max volume ≈ 7.84468782041). By inspecting the resulting matrix,
a pattern was observed: the matrix can be written using sin/cos of two angles:

```
P(x,y) = [ sx   sx   cx   cx  -sx  -sx   cx   cx ]
          [ cx   cx   sx   sx   cx   cx  -sx  -sx ]
          [ sy  -sy   cy  -cy  -cy   cy   sy  -sy ]
          [ cy  -cy   sy  -sy   sy  -sy  -cy   cy ]
```

where sx=sin(x), cx=cos(x), sy=sin(y), cy=cos(y).

This is a **2-parameter family** within the 16-dimensional Grassmannian Gr(4,8).

**Key property:** PP^T = 4I₄ automatically — the rows are orthogonal with
equal norm 2. This makes the 8 projected generators a **tight frame** in ℝ⁴,
which is a necessary condition for volume maximization (Ivanov 2018/2021).

## Established Results

### Result 1: Closed-Form Volume

V(x,y) = 2 + sin(2x)/2 + 3sin(2y)/2 + 2cos(2x) + 2cos(2y) + 3cos(2x)cos(2y)/2

Verified numerically: matches the explicit C(8,4)=70 determinant computation
to machine precision at multiple test points.

### Result 2: Critical Point Equations

Setting ∇V = 0:

    cot(2x) = 4 + 3cos(2y)       ... (I)
    3cot(2y) = 4 + 3cos(2x)      ... (II)

Optimal angles (50-digit precision):

    x = 0.073480735017031270149159906654482271677996672574569
    y = 0.20328550318676595938577285407680349276721326173472

Optimal volume (50-digit precision):

    V = 7.8446878204079561121997603720301304618149256962958

### Result 3: Algebraic Nature

u = cos(2x) satisfies the **irreducible** degree-8 polynomial over ℚ:

    2025u⁸ + 10800u⁷ + 24840u⁶ + 19848u⁵ − 18368u⁴ − 51744u³ − 24448u² + 21504u + 16384 = 0

Note: 2025 = 45² = (3²·5)², and 16384 = 2¹⁴.

v = cos(2y) satisfies a different irreducible degree-8 polynomial:

    11745v⁸ + 62640v⁷ + 116712v⁶ + 58920v⁵ − 78272v⁴ − 107040v³ − 28928v² + 10752v + 4096 = 0

The volume V ≈ 7.845 is algebraic but its minimal polynomial has very large
coefficients (no integer relation found up to degree 32 with coefficients < 10¹²).

### Result 4: The 4D Polytope — f-vector

    f-vector: (128, 352, 336, 112)

This matches the **general position** formulas for a zonotope Z(8,4):

| Element   | Count | Formula                              |
|-----------|-------|--------------------------------------|
| Vertices  |   128 | 2·(C(7,0)+C(7,1)+C(7,2)+C(7,3)) = 2·64 |
| Edges     |   352 | 8·2·(C(6,0)+C(6,1)+C(6,2)) = 8·44   |
| 2-faces   |   336 | C(8,2)·2·(C(5,0)+C(5,1)) = 28·12    |
| 3-cells   |   112 | 2·C(8,3) = 2·56                      |
| Euler     |     0 | 128 − 352 + 336 − 112 = 0 ✓         |

Properties:
- All 352 edges have **equal length** (1/√2) → equilateral zonotope
- All 336 faces are parallelograms
- All 112 cells are parallelotopes (combinatorial cubes), 7 metric types × 16 each
- Centrally symmetric (as all zonotopes are)

### Result 5: Symmetry Group — D₄ × Z₂ (order 16)

Element order distribution: {1: 1, 2: 7, 4: 8}
Center: Z₂ × Z₂ (order 4)

Generators:
- a: (x₁,x₂,x₃,x₄) → (−x₂, x₁, −x₃, x₄)  [order 4, 90° rot in (1,2)-plane + negate x₃]
- b: (x₁,x₂,x₃,x₄) → (x₂, x₁, x₄, x₃)    [order 2, swap(1↔2) + swap(3↔4)]
- Central inversion −I is always present

The comprehensive search (checking all signed permutations B₄ of order 384
plus all possible orthogonal transforms mapping generators to ±generators)
found exactly 16 symmetries. The group is closed.

### Result 6: The Pattern Breaks at n=4

| Projection | Shape                    | Symmetry         | Algebraic connection  |
|------------|--------------------------|------------------|-----------------------|
| 4→2       | Regular octagon          | D₈ (order 16)   | Silver ratio 1+√2    |
| 6→3       | Rhombic triacontahedron  | Iₕ (order 120)  | Golden ratio φ        |
| **8→4**   | **Generic equilateral zonotope** | **D₄×Z₂ (order 16)** | **Degree-8 algebraic** |

In 2D/3D, maximally symmetric tight frames happen to also maximize volume.
In 4D, the volume-maximizing tight frame has only modest symmetry (16 out
of B₄'s maximum 384).

### Result 7: Literature

- Ivanov (2018/2021), "Maximization of the volume of zonotopes,"
  arXiv:1804.10055, Can. Math. Bull. 64, 942–963.
  - Proves tight frame condition is **necessary** for local maximum
  - Proves optimality for k=1,2 and n−k=1,2
  - The 8→4 case (k=4, n=8) remains **open** for rigorous proof

### Result 8: The Polytope Has No Standard Name

It is NOT any regular, uniform, or root-system polytope.
Best description: "the equilateral 4-zonotope Z(8,4) with D₄×Z₂ symmetry
that maximizes the 8-cube shadow volume."

## Open Question

### Conjecture: The sin/cos family achieves the global maximum

The sin/cos parameterization is a **2-parameter family** within the
**16-dimensional** Grassmannian Gr(4,8). Does its maximum (≈ 7.84469)
equal the global maximum over all 4D subspaces?

**Evidence for the conjecture:**
- The original unconstrained optimization (max_shadow.py, max_shadow_8_4.py)
  with 32 free parameters finds the same value ≈ 7.84469
- The sin/cos family automatically satisfies the tight frame necessary
  condition
- The test_sincos_conjecture.py script (partially run, interrupted) showed
  that 30 basin-hopping trials with general 32-parameter optimization all
  converged to ≤ 7.844687820408, matching the sin/cos optimum

**To finish verifying:** Run `test_sincos_conjecture.py` to completion
(takes ~20 min). If the general optimum matches, the conjecture is
numerically supported. A rigorous proof would require showing that the
2-parameter family is a critical submanifold of the Grassmannian.

**Deeper question:** Is there a structural reason WHY the global optimum
lives in this 2-parameter family? The sin/cos structure imposes a specific
block structure on P. What makes this block structure special?
