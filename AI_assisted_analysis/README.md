# Maximum Shadow Projections of Hypercubes

## Problem Statement

Find the k-dimensional subspace W ⊂ ℝⁿ that maximizes Vol_k(proj_W([0,1]ⁿ)).

Equivalently: maximize the volume of the zonotope generated by projecting
the n standard basis vectors of ℝⁿ onto a k-dimensional subspace.

**Duality:** The n→k and n→(n−k) problems are related. The solved cases are
k = 1, 2, n−1, n−2 (the first two by direct construction, the latter two by
duality).

## Methods and Tools

**Volume computation:** For a k×n projection matrix P with rows spanning
the subspace, the shadow volume is V = Σ_{|S|=k} |det(P_S)| / det(PP^T)^{1/2},
summing over all C(n,k) subsets of k columns.

**Optimization:** Basin-hopping + L-BFGS-B on the space of k×n matrices,
with tight-frame normalization PP^T = (n/k)I_k. Validated with Nelder-Mead
and Stiefel manifold gradient ascent. Tight frame is a necessary condition
for any local maximum (Ivanov 2018).

**Symmetry computation:** For each optimum, find all R ∈ O(k) mapping the
generator set {±g_i} to itself. Uses brute-force search over
Perm(n,k) × {±1}^k candidate mappings, constructing R and verifying.

**General-purpose tool** (`max_shadow_generic.py`, in repo root):

    python max_shadow_generic.py <n> <k> [--trials N] [--niter N] [--seed S]

Searches over all k-dimensional subspaces of ℝⁿ (no structural assumptions)
using basin-hopping with tight-frame normalization. Prints the maximum
shadow volume, the k×n projection matrix, all n generators in ℝ^k with
norms and pairwise inner products, and the expected f-vector.

**Literature:**
- Ivanov (2018/2021), "Maximization of the volume of zonotopes,"
  arXiv:1804.10055, Can. Math. Bull. 64, 942–963.
  - Proves tight frame condition is **necessary** for local maximum
  - Proves optimality for k=1,2 and n−k=1,2
  - Cases with k ≥ 3 and n−k ≥ 3 remain **open** for rigorous proof

### Observations

- Cases with k ∈ {1, 2, n−1, n−2} always have high symmetry (duality).
- Equilateral tight frames are optimal for n = 4, 5, 6, 10, 12 in 3D,
  and n = 5, 6, 8 in 4D. NOT equilateral for n = 7, 8, 9, 11 in 3D,
  and n = 7, 9, 10, 11, 12 in 4D.
- Among genuinely non-trivial cases (k ≥ 3 and n−k ≥ 3), the highly
  symmetric ones are: **6→3** (I_h), **10→3** (I_h), **12→3** (O_h),
  and **8→3** (D₇×Z₂).
- For n→4 with n ≥ 9, all cases tested have symmetry ≤ 4. The 4D
  landscape is much less friendly to symmetry than 3D.

### 8→3: D₇ × Z₂ Zonotope (order 28)

**Conjecture (numerical):** The 8→3 optimum has the (7+1) decomposition:
seven equally spaced unit vectors lifted onto a cone, plus one axial vector.
This is supported by basin-hopping, Nelder-Mead, and Stiefel gradient ascent
over the full Grassmannian Gr(3,8) with no structural assumptions, but is
**not proven** (k=3, n−k=5 falls outside the range of Ivanov's theorem).

**Conditional results (all below assume the (7+1) structure):**

Parameterization:

    g_k = (r·cos(2πk/7), r·sin(2πk/7), h)   for k = 0,...,6
    g₇  = (0, 0, b)

    r = 4/√21   (fixed by tight frame)
    b = √(8/3 − 7h²)

| Property | Value |
|----------|-------|
| Volume | 7.0270375786 |
| f-vector | (58, 112, 56) |
| Symmetry | D₇ × Z₂ (order 28) |
| Free parameters | **1** (h ≈ 0.4826) |
| Not equilateral | cone ≈ 0.997, axial ≈ 1.018 |

The (7+1) decomposition works for 8→3 but NOT for 7→3 (2.3% below)
or 9→3 (1.6% below). The xy-radius r = 4/√21 is fixed by the
tight-frame condition; only h is optimized.

**Exact algebraic values (proved, given the (7+1) structure):**

    r² = 16/21
    h² = (2/21)(1 − ρ + ρ²)
    b² = 2 + (2/3)ρ − (2/3)ρ²
    h·b = 2/7 + (2/7)ρ − (2/21)ρ²
    h/b = (−1 + 6ρ − 2ρ²)/7

All key quantities — r², h², b², and the product h·b — are in the heptagonal
field ℚ(ρ). This is what makes exact vZome realization possible: the Gram
matrix is entirely over ℚ(ρ). Note that r/h is NOT in ℚ(ρ) (field norm
512/7 is not a perfect square), so the generators cannot be axis-aligned.

**Derivation of the exact h:**

The sum of absolute 3×3 subdeterminants of the generator matrix is

    D(h) = r² h S₁ + r² b S₂

where b = √(8/3 − 7h²) and S₁, S₂ are trigonometric sums over subsets
of the 7 cone generators:

    S₁ = Σ_{i<j<k<7} |sin(δ_ij) + sin(δ_jk) − sin(δ_ik)|    (35 triple terms)
    S₂ = Σ_{i<j<7}   |sin(δ_ij)|                              (21 pair terms)

with δ_ij = 2π(j−i)/7. These arise from the 3×3 subdeterminants:

    det([g_i | g_j | g_k]) = r²h (sin δ_ij + sin δ_jk − sin δ_ik)   (3 cone)
    det([g_i | g_j | g₇])  = r²b sin δ_ij                           (2 cone + axial)

The shadow volume is V(h) = D(h) / (8/3)^{3/2}. Since the denominator is
constant, maximizing D(h) suffices. Setting dD/dh = 0:

    S₁ b = 7h S₂
    h² = 8S₁² / (3(7S₁² + 49S₂²))

Mathematica simplifies the trigonometric sums to:

    S₁ = 7(3cos(π/14) + 5cos(3π/14) + sin(π/7))
    S₂ = 7(  cos(π/14) +  cos(3π/14) + sin(π/7))

and confirms **symbolically** (not just numerically) that the optimal h²
has the closed form:

    h² = 8S₁² / (3(7S₁² + 49S₂²)) = (2/21)(1 − ρ + ρ²)

where ρ = 2cos(π/7). (Verified: `FullSimplify[h²_derived − h²_target] = 0`
in Wolfram Language. See `verify_8_3_symbolic.wls`.)

**Shadow volume as a function of h:**

    V(h) = √(2/3) cos(π/14) [√(24−63h²)(cos(π/7)+sin(π/14)) + 3h(−1+5cos(π/7)+sin(π/14))]

valid for 0 < h < √(8/21). The maximum V = 7.0270375786 is the largest
real root of

    V⁶ − 56V⁴ + 336V² − 448 = 0

i.e. V² satisfies the irreducible cubic y³ − 56y² + 336y − 448 = 0
(discriminant 2¹²·7²·13²).
Note: V is NOT in ℚ(ρ) — it generates a different cubic field.

**vZome realization (exact, conditional on the conjecture):**

The zonotope can be exactly modeled in vZome's heptagonal field ℚ(ρ).
This is possible because the Gram matrix G_ij = ⟨g_i, g_j⟩ is entirely
over ℚ(ρ) (see the algebraic values above). vZome's physical metric
includes a shear transform (see `embedInR3` in `HeptagonalAntiprismSymmetry.java`):

    x_phys = x_raw + y_raw/(2σ),  y_phys = y_raw·sin(3π/7),  z_phys = z_raw

so the physical inner product in raw coordinates is
⟨u,v⟩ = u_x v_x + u_y v_y + u_z v_z + c(u_x v_y + u_y v_x), where
c = 1/(2σ) ∈ ℚ(ρ). Under this metric, the generators are:

    μ  = 3ρ + (3/2)ρ²       (z-height of the 7 cone generators)
    ν  = 12 + 12ρ + 3ρ²      (axial generator z-component)
    w₀ = (−6−6ρ−6ρ², 6ρ², 0)  (seed vector for the 7-fold orbit)

Generators G_k = R₇ᵏ(w₀) + (0,0,μ) for k=0,...,6 and G_7 = (0,0,ν), where
R₇ is the heptagonal rotation matrix. Since r/h ∉ ℚ(ρ), the generators
are necessarily rotated relative to vZome's heptagonal frame axes. All
vertex coordinates are integers in vZome's (1, ρ, σ) encoding:

    G_0: -4 -2 -2   2  0  2  1  2 1
    G_1:  2 -2 -4   0  0 -2  1  2 1
    G_2: -2 -2  2  -4 -2 -2  1  2 1
    G_3:  2  4  0   2 -2 -4  1  2 1
    G_4:  0  2  4  -2 -2  2  1  2 1
    G_5:  2  0  2   2  4  0  1  2 1
    G_6:  0  0 -2   0  2  4  1  2 1
    G_7:  0  0  0   0  0  0  5  4 1

The vZome file contains the full projected 8-cube (256 vertices, 1024 edges).

**Verification:** The formula h² = (2/21)(1−ρ+ρ²) is proved symbolically
(`FullSimplify` = 0 in Wolfram Language; see `verify_8_3_symbolic.wls`)
and numerically (mpmath, 50 digits). Independent shape-ratio test
(z_range/xy_diameter) comparing Euclidean generators vs vZome physical
embedding matches to 2×10⁻¹⁶ (float64 machine precision; see
`verify_8_3_vzome.py`).

### 10→3: Rhombic Enneacontahedron (I_h, order 120)

The 10 generators are the **three-fold rotation axes** of the icosahedron
(face-center directions, 20 faces → 10 antipodal pairs), equivalently
**half the vertices of the regular dodecahedron** (the dual of the
icosahedron). Zero free parameters.

**Exact symbolic generators** (φ = (1+√5)/2, N = √((21+9√5)/2)):

Type A — 6 generators from cyclic permutations of (φ, 0, 2+√5)/N:

    g₀ = (+φ,   0,    2+√5)/N        g₄ = (0,    2+√5, +φ)/N
    g₁ = (−φ,   0,    2+√5)/N        g₇ = (0,    2+√5, −φ)/N
    g₈ = (2+√5, +φ,   0)/N           g₉ = (2+√5, −φ,   0)/N

Type B — 4 generators (±φ², ±φ², ±φ²)/N, one from each antipodal pair:

    g₂ = (+φ², +φ², +φ²)/N = (1, 1, 1)/√3
    g₃ = (−φ², +φ², +φ²)/N
    g₅ = (+φ², +φ², −φ²)/N
    g₆ = (−φ², +φ², −φ²)/N

where φ² = (3+√5)/2 = φ+1. All 10 are unit vectors, PP^T = (10/3)I₃.

### 12→3: O_h Zonotope with Silver Ratio (order 48)

The 12 generators are the **O_h orbit of (a, a, b)** on the unit sphere,
where **b/a = 1 + √2** (the silver ratio), equivalently **half the vertices
of the small rhombicuboctahedron** (whose 24 vertices are all permutations
of (±1, ±1, ±(1+√2))).

    a² = (5 − 2√2) / 17
    b  = a · (1 + √2)

The orbit consists of all sign changes and permutations of (a, a, b):
3 choices for which coordinate gets b × 8 sign combinations = 24 points
= 12 antipodal pairs.

| Property | Value |
|----------|-------|
| Volume | 13.5096139098 |
| f-vector | (134, 264, 132) |
| Symmetry | O_h (order 48) — full octahedral |
| Generators | O_h orbit of (a, a, b) with b/a = 1+√2 |
| Free parameters | **0** (silver ratio uniquely determined) |

The silver ratio 1+√2 also appears in the 4→2 case (regular octagon).

### 15→3: Icosahedral Conjecture — REFUTED

The conjecture that the 15 two-fold axes (edge midpoints) of the icosahedron
maximize volume is **false**:

| | Volume |
|---|--------|
| Icosahedral (15 edge-center directions) | 18.497 |
| Numerical maximum | 19.090 |
| Deficit | 3.11% |

The icosahedral pattern holds for five-fold axes (6→3) and three-fold axes
(10→3) but breaks for two-fold axes (15→3).

### Icosahedral zonohedra summary

| Case | Icosahedral axes | Zonohedron | Faces | Optimal? |
|------|-----------------|------------|-------|----------|
| 6→3 | 6 five-fold (vertex pairs) | Rhombic triacontahedron | 30 | ✓ |
| 10→3 | 10 three-fold (face-center pairs) | Rhombic enneacontahedron | 90 | ✓ |
| 15→3 | 15 two-fold (edge-midpoint pairs) | — | — | ✗ (3.1% below) |

Both 6→3 and 10→3 have zero free parameters: the generators form a single
orbit under I_h, which forces equal norms and uniquely determines the subspace.

## n→4 Special Cases

### 8→4: The Sin/Cos Parameterization (D₄ × Z₂, order 16)

The optimal 4×8 projection matrix can be written using sin/cos of two angles:

```
P(x,y) = [ sx   sx   cx   cx  -sx  -sx   cx   cx ]
          [ cx   cx   sx   sx   cx   cx  -sx  -sx ]
          [ sy  -sy   cy  -cy  -cy   cy   sy  -sy ]
          [ cy  -cy   sy  -sy   sy  -sy  -cy   cy ]
```

PP^T = 4I₄ automatically. This is a 2-parameter family within Gr(4,8).

#### Closed-form volume

V(x,y) = 2 + sin(2x)/2 + 3sin(2y)/2 + 2cos(2x) + 2cos(2y) + 3cos(2x)cos(2y)/2

#### Critical point equations

    cot(2x) = 4 + 3cos(2y)       ... (I)
    3cot(2y) = 4 + 3cos(2x)      ... (II)

Optimal angles (50-digit precision):

    x = 0.073480735017031270149159906654482271677996672574569
    y = 0.20328550318676595938577285407680349276721326173472
    V = 7.8446878204079561121997603720301304618149256962958

#### Algebraic nature

cos(2x) satisfies the **irreducible** degree-8 polynomial over ℚ:

    2025u⁸ + 10800u⁷ + 24840u⁶ + 19848u⁵ − 18368u⁴ − 51744u³ − 24448u² + 21504u + 16384 = 0

(2025 = 45² = (3²·5)², 16384 = 2¹⁴)

cos(2y) satisfies a different irreducible degree-8 polynomial:

    11745v⁸ + 62640v⁷ + 116712v⁶ + 58920v⁵ − 78272v⁴ − 107040v³ − 28928v² + 10752v + 4096 = 0

#### The 4D polytope

| Property | Value |
|----------|-------|
| f-vector | (128, 352, 336, 112) — Z(8,4) general position |
| Edges | All 352 have **equal length** (equilateral zonotope) |
| 2-faces | 336 parallelograms |
| 3-cells | 112 parallelotopes (7 metric types × 16 each) |
| Symmetry | D₄ × Z₂ (order 16) |

Symmetry generators:
- a: (x₁,x₂,x₃,x₄) → (−x₂, x₁, −x₃, x₄) [order 4]
- b: (x₁,x₂,x₃,x₄) → (x₂, x₁, x₄, x₃) [order 2]
- Central inversion −I

The polytope has no standard name. It is NOT any regular, uniform, or
root-system polytope.

#### Sin/cos conjecture — VERIFIED (numerical)

The sin/cos family achieves the global maximum over all 4D subspaces.
This is verified numerically (3 independent methods, no structural
assumptions) but not proved:
- **Basin-hopping** (40 trials, 32 parameters): matches to 2.4×10⁻¹¹
- **Nelder-Mead** (30 random starts): consistent
- **Stiefel manifold gradient ascent** (20 trials): consistent

#### Block decomposition (numerical evidence, NOT a proof)

The optimal subspace V decomposes as **V = V₁ ⊕ V₂** (two orthogonal 2D
subspaces). The 8 generators pair as (g₀,g₁), (g₂,g₃), (g₄,g₅), (g₆,g₇):
- g₂ₖ = (aₖ, bₖ) and g₂ₖ₊₁ = (aₖ, −bₖ)
- Pair sums lie in V₁, pair differences lie in V₂

This is observed in 10/10 independent optimization trials (cross-block norm
= 0.0000000000 in all cases). If the block decomposition is necessary, it
explains the 2-parameter family: tight frame removes ~7 dimensions, block
decomposition removes ~5 more, leaving 1 angle per 2D block.

**This is numerical evidence, not a rigorous proof.** The tight frame
condition is a theorem (Ivanov 2018); the block decomposition is an
unproven conjecture.

#### Orbit under B₈

- |Stabilizer| = 16 (= D₄×Z₂ itself)
- Orbit size = |B₈|/16 = 10,321,920/16 = **645,120 distinct optimal subspaces**
- All have the same symmetry group
- 28 distinct (x,y) angle pairs within the sin/cos family
- Higher symmetry (order 32) exists at x=y but with 0.8% volume deficit

### Comparison: the 2n→n diagonal

| Projection | Shape | Symmetry | Algebraic connection |
|------------|-------|----------|---------------------|
| 4→2 | Regular octagon | D₈ (order 16) | Silver ratio 1+√2 |
| 6→3 | Rhombic triacontahedron | I_h (order 120) | Golden ratio φ |
| **8→4** | Generic equilateral zonotope | D₄×Z₂ (order 16) | Degree-8 algebraic |

In 2D and 3D, maximally symmetric tight frames coincide with
volume-maximizing ones. In 4D, **symmetry and volume compete** — the
highest-symmetry tight frame achieves only 99.2% of the maximum volume.
